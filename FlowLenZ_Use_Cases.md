# FlowLenZ — Use Cases

**Product:** FlowLenZ — AI Intelligence for Genesys Cloud Architect  
**Source:** *FlowLenZ Use Cases.docx* (PS Hackathon 2026)

---

## Use Case 1 — Explain the flow

Architect flow is on the **left**; **FlowLenZ** is on the **right**.

A user opens an Architect flow (for example **version 1**) and asks FlowLenZ to **explain the flow**. FlowLenZ explains it using **AI integrated on the backend**.

---

## Use Case 2 — Change intelligence while building

On top of **version 1**, the user **edits** and creates **version 2**. While editing, FlowLenZ shows:

- Continuous **lint** for common mistakes, bad patterns, and quality issues  
- **Version comparison** and **customer-journey** explanation of what changed  
- **Dependency impact** from changes  
- **Risk score** for the changes  
- **Potential regression tests** to cover  

Before **publishing**, FlowLenZ provides **visual change intelligence**, **testing recommendations**, **risk assessment**, and **approval summaries**.

Each version is turned into **human-readable change documentation** and **release notes**, so teams can build and publish Architect flows with confidence.

Use Case 2 is **real-time information** between Architect UI and FlowLenZ.

---

## Use Case 3 — Supervisor review after publish

Once **version 2 is published**, when a **supervisor** opens **flow version 2**, FlowLenZ displays the same information as in Use Case 2 (**a–g**) so the supervisor can **evaluate the risk** of the changes before **approving the flow for production** deployment.
